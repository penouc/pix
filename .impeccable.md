## Design Context

### Users
Local developers configuring coding-agent providers and models before starting a task.
Prospective users discovering PiX via a promotional landing page — individual developers who want a local, reviewable coding agent.

### Brand Personality
Focused, restrained, trustworthy.

### Aesthetic Direction
**Desktop app:** A compact dark preference page that matches the existing desktop workbench and keeps credential handling explicit.

**Marketing site:** A simple light landing page. Soft mint/sage ground tied to the PiX mascot (olive green + orange eye accent). Brand-first hero, minimal sections, no dashboard chrome. Chinese-first copy for promotion.

### Design Principles
- Keep provider configuration scannable.
- Never expose stored credentials after saving.
- Make configured state and selected defaults obvious.
- Prefer direct controls over decorative chrome.
- Marketing: one job per section; brand over headline; CTA to GitHub until a download exists.
