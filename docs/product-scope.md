# PiX Product Scope (MVP freeze)

Source of truth: [`./product-and-engineering-plan.md`](./product-and-engineering-plan.md) §1–3, §18.

## In scope

- Open local Git project + trust
- Provider/Model selection (via Pi)
- Agent read/write/edit/bash with approval pipeline
- Streaming chat + tool cards
- Multi-file Diff review
- Keep / Revert with checkpoint restore
- Session recovery after restart

## Out of scope (MVP)

- Full IDE editing
- Multi-agent orchestration
- Cloud sync / team collaboration
- Plugin marketplace
- Local model as launch requirement
- Plan Mode, Session Fork, MCP, auto-update, multi-window
